Daily Ledger - install guide

1. Ei folder-er shob file (index.html, manifest.webmanifest, sw.js, icon-*.png) ekshathe kono free hosting-e upload korun
   (Netlify Drop, GitHub Pages, ba Cloudflare Pages). Hosting apnake ekta https link dibe.
2. Phone-e oi link khulun.
   - Android (Chrome): menu (3 dot) > Install app / Add to Home screen
   - iPhone (Safari): Share button > Add to Home Screen
3. Home screen-e "Ledger" icon ashbe. Eita app-er moto khulbe, internet charao cholbe.

Hisab shudhu oi phone-er browser storage-e thake. App-er niche "Save backup" diye majhe majhe backup file save korun.
